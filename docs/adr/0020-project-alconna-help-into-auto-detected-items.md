# Project Alconna Help Into Auto-Detected Items

PicMenu Next builds an automatically detected function item from Alconna's public command surface: the command name, primary invocation and shortcuts, description, formatted help, and usage fallback. A plugin author may override each PicMenu field when a curated presentation is needed. This avoids maintaining two complete help descriptions by default while preserving deliberate control over wording, trigger guidance, and detail where the generated result is not suitable.
